# 首页真实工作台轮播设计

## 目标

首页研究台不再展示固定示例或不可点击的“查看原文”。登录用户看到的是自己最近完成分析的真实工作台；多个工作台以单卡形式轮播，每个工作台停留 20 秒。所有来源入口必须经过当前数据库记录校验后才出现。

## 数据与排序

- 以 `conversations.updated_at` 作为“最近完成分析”的跨设备活动时间，不新增仅保存在浏览器中的状态。
- 只读取当前用户、状态为 `COMPLETED` 的会话，按更新时间倒序聚合为最多三个不同知识库。
- 每个知识库使用其最近完成会话中的最新助手消息。优先展示第一张拥有有效 `document_id` 的证据卡。
- 证据卡的 `document_id` 必须对应当前用户拥有、未进入回收站且属于该知识库的真实资料；显示的文件名以 `documents.original_name` 为准，不相信历史快照中的文件名。
- 没有有效证据卡但确实完成过分析的工作台，可以显示真实工作台状态和“继续研究”入口，但不显示来源、页码或“查看原文”。
- 没有任何已分析工作台时，显示真实空状态，并引导进入知识库；不再使用长征等演示数据。

## 跳转规则

- 工作台名称、问题标题与“继续研究”跳转至 `/assistant?libraryId=<id>`。
- 有效来源的“查看原文”跳转至 `/api/documents/<id>/file`；PDF 携带合法页码参数。
- 文件资料打开 Supabase 限时签名地址；文字资料由同一路由以只读纯文本形式打开。
- 已删除、找不到或无法唯一匹配的资料不生成来源链接。

## 视觉与动效

- 保留现有数字研究台、暖纸张与深靛蓝视觉体系，不改首页整体结构。
- 每次仅展示一个真实工作台，最多轮播三个。停留 20 秒后，当前内容以轻微下沉、透明度下降和背景虚化退出；下一项以反方向位移、清晰度恢复进入。
- 进度指示器用 20 秒细线填充表达剩余时间；用户点击指示器可立即切换。
- 鼠标进入或键盘聚焦研究台时暂停轮播；离开后从当前工作台重新计时。
- 卡片悬停仅增加约 1.012 倍缩放、柔和靛蓝轮廓与局部玻璃光泽。遵循 `prefers-reduced-motion`，减少动效时停止自动轮播并直接切换。

## 可靠性与失败状态

- 页面查询失败时显示中性的“暂时无法读取最近研究”状态和工作区入口，不伪造内容。
- 页面展示的“来源可回溯”只用于已通过文档存在性、归属和未删除校验的证据卡。
- HiAgent 返回同名资料且无法唯一定位时，不绑定 `document_id`，避免错误跳转。
- 前端和测试不得保存、输出或渲染任何 API 密钥。

## 验证

- 单元测试覆盖：真实工作台排序与去重、文档归属校验、无数据空状态、文件与文字来源链接、20 秒轮播和减少动效。
- 路由测试覆盖：删除资料拒绝打开、文字资料返回只读正文、文件资料仍生成签名跳转。
- 本地浏览器验证登录首页、多个工作台切换、暂停、手动切换及全部链接。
