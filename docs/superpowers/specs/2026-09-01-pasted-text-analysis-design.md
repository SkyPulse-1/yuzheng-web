# 粘贴文字分析测试功能设计

## 目标

在知识库文档页面的上传区域下方增加一个临时测试功能，让已登录用户粘贴一段文字并调用现有 HiAgent 对话 API 获取真实分析结果。该功能用于验证 HiAgent 的文本分析能力，不作为文档知识库正式接入方案。

## 用户界面

- 位置：当前知识库页面的文档上传区域下方。
- 样式：沿用现有纸张色、石色边框、琥珀色强调色、圆角卡片和按钮样式。
- 标题：`粘贴文字分析`
- 状态标识：`测试功能`
- 说明：`复制一段文字，在不上传文件的情况下测试内容分析。`
- 输入框：多行文本框，最多 8000 个字符，并显示剩余字数。
- 主按钮：`开始分析`
- 辅助按钮：分析完成后显示 `清空内容`。
- 处理中状态：`正在分析内容…`
- 结果区域：按 HiAgent 返回内容原样显示，保留换行，使用与现有回答卡一致的排版。
- 页面不出现“提示词”“Prompt”“系统指令”等技术语言。

## 行为与数据流

1. 用户在当前知识库页面粘贴文字。
2. 浏览器向新的 `POST /api/text-analysis` 发送当前 `libraryId` 和 `text`。
3. 服务端验证登录状态、知识库访问权、文本非空和 8000 字限制。
4. 服务端使用现有 `createHiAgentConversation` 创建一次性 HiAgent 对话。
5. 服务端把固定分析要求与用户原文组合为一次查询，通过现有 `chatWithHiAgent` 发送给学校 HiAgent。
6. 服务端只返回分析文本，不写入 `conversations`、`messages`、`documents` 或 Storage。
7. 浏览器在当前页面显示结果；刷新或离开页面后结果消失。

固定分析要求包含四个部分：内容摘要、关键观点、可核验的原文依据、信息不足或歧义。分析必须以粘贴原文为范围，不补充原文以外的事实。该要求仅在服务端使用，不展示在页面上。

## 隐私边界

- 语证应用不把粘贴原文或结果保存到 Supabase 数据库、Storage、日志或 Git。
- 原文会发送给学校 HiAgent 服务以完成本次分析；HiAgent 平台自身的处理与日志规则由学校平台政策决定。
- 页面提示用户不要粘贴不允许发送到学校服务的敏感内容。
- 不读取、展示或修改 HiAgent API Key，也不修改 HiAgent 后台配置。

## 接口约定

请求：

```json
{
  "libraryId": "uuid",
  "text": "需要分析的原文"
}
```

成功响应：

```json
{
  "answer": "HiAgent 返回的分析文本"
}
```

错误响应统一使用：

```json
{
  "error": "适合用户阅读的中文说明"
}
```

## 错误处理

- 未登录：返回 `401` 和 `请先登录。`
- 知识库不存在或当前用户不可访问：返回 `404`。
- 文本为空或超过 8000 字：返回 `400`。
- HiAgent 未配置：返回 `503`。
- HiAgent 请求失败或超时：返回 `502`，保留用户输入以便重试。
- 重复点击：按钮在请求期间禁用，不发送第二次请求。

## 测试要求

- 单元测试覆盖文本清理、空文本、8000 字边界和超限拒绝。
- 接口测试覆盖未登录、知识库不可访问、HiAgent 未配置和成功响应。
- 组件测试覆盖按钮禁用、字符计数、成功结果、失败提示和清空操作。
- 运行现有全部测试、ESLint 和生产构建，确保不影响注册登录、Library CRUD、文档上传和知识库问答。
- 本地人工验证使用非敏感测试文字；真实调用前不自动创建账号或上传文件。

## 非目标

- 不把粘贴文字保存为文档。
- 不生成伪造页码或文档来源证据卡。
- 不接入 HiAgent 文件上传服务。
- 不修改正式文档处理流程。
- 不在本次测试功能中保存历史记录。
