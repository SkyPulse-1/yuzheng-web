# Library CRUD 阶段设计

## 范围

本阶段实现登录用户的逻辑知识库管理：列表、创建、查看、编辑和删除。文档上传、火山知识库和 HiAgent 均不在本阶段接入。

## 数据模型与安全

`public.libraries` 使用 UUID 主键，保存 `owner_id`、名称、描述和创建/更新时间。名称限制 1–50 字，描述限制 0–200 字。所有读写均启用 RLS，并以 `auth.uid() = owner_id` 为权限边界；浏览器提交的 owner_id 永远不会被信任。

## 路由与接口

- `/dashboard`：展示最近知识库与快捷入口。
- `/libraries`：知识库列表、创建、编辑和删除。
- `/libraries/[id]`：知识库详情；文档区域在下一阶段开放。
- `GET/POST /api/libraries`：列出和创建当前用户知识库。
- `GET/PATCH/DELETE /api/libraries/[id]`：查看、修改和删除当前用户知识库。

未登录返回 401；不存在或不属于当前用户的资源统一返回 404，避免泄露资源归属。删除前由界面二次确认。

## 验收

登录用户可创建多个知识库、看到自己的列表、修改名称/描述、进入详情并删除。数据库 RLS 保证用户之间互不可见。
