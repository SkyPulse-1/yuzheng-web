# 首页最近证据卡与 500MB 上传设计

## 目标

在不扩大首页占用空间的前提下，让用户回到语证时快速看到最近阅读过的证据卡；同时将单个文件上传上限统一调整为 500MB，并把用户可见提示改成自然、直接的产品语言。

## 首页证据卡

首页保留现有单卡片区域，不增加卡片网格。已登录用户有阅读记录时，展示最近打开的最多 3 张证据卡，每 5 秒淡出并切换到下一张；提供上一张、下一张和圆点定位，鼠标或键盘焦点停留在卡片上时暂停自动切换。

卡片继续展示观点、关键原文、来源文档和页码。用户点击“查看关键原文”或“查看原文”时，系统记录该卡片为最近打开。再次打开同一卡片只更新时间，不产生重复记录。记录保存在 Supabase，因此同一账号在不同设备登录后能看到一致的最近记录。

已登录但从未打开过证据卡的用户，以及未登录访客，继续看到现有“长征战略意义比较”示例卡。只有两张或以上真实卡片时才自动轮播；一张卡片保持静止。

## 数据设计

新增 `evidence_card_views` 表，保存用户、会话、卡片标识、展示所需的卡片快照和最后打开时间。对用户、会话和卡片标识建立唯一约束，对用户和打开时间建立查询索引。

启用行级权限：用户只能读取、写入和更新自己的记录。浏览器不接触服务端密钥。首页服务端只读取当前登录用户最近 3 条记录；未登录时不查询私人数据。

## 上传限制

前端文件选择校验、上传接口校验、页面说明和环境变量示例统一为单文件 500MB。超过限制时直接说明“单个文件不能超过 500MB，请压缩或拆分后重试”。

该限制是语证应用层限制。Supabase Storage 项目本身还需要允许至少 500MB 的文件；若服务端套餐或存储桶限制更低，界面显示实际失败原因，不把上传失败显示为成功。

## 文案原则

用户可见文本只说明当前状态、发生的事情和下一步操作。删除“提示词”“智能体思考”“AI 生成”等对用户无帮助的表达；不暴露模型、检索分数、内部接口名和开发术语。

保留产品名称和必要的业务名词，例如“知识库”“证据卡”“来源文档”。第三方服务名只在设置或错误排查确有必要时出现。

## 顶部导航

登录后的左上角“语证”品牌标志返回公开产品首页 `/`。右侧导航将原“首页”改名为“工作台”，指向 `/dashboard`；“知识库”继续指向 `/libraries`。当前所在区域使用明显的深色底色突出：Dashboard 激活“工作台”，知识库列表、知识库详情和证据问答激活“知识库”。

## 状态与异常

- 最近记录读取失败：首页仍显示长征示例，不阻止用户进入登录或工作区。
- 记录最近打开失败：不影响查看证据卡和原文。
- 自动切换遵守系统“减少动态效果”设置；启用该设置时不自动轮播，仅允许手动切换。
- 文件超过 500MB：在请求发出前拦截；服务端继续进行同样校验，避免绕过前端。

## 验收标准

- 单个不超过 500MB 的受支持文件可进入上传流程，超过 500MB 的文件得到明确提示。
- 打开一张真实证据卡后返回首页，该卡片成为第一张展示内容。
- 最近记录最多展示 3 张，同一卡片不会重复出现。
- 多张记录每 5 秒淡入淡出切换，支持手动切换、悬停暂停和减少动态效果。
- 没有记录的新用户和未登录访客看到现有长征示例。
- 用户之间不能读取或改写彼此的最近记录。
- 页面不出现提示词式、模型式或内部开发式语言。
- 品牌标志、工作台和知识库三个入口职责清晰，当前区域有明确选中状态。
- `npm run lint`、自动化测试和 `npm run build` 通过。

## 不在本轮范围

本轮不改变支持的文件格式，不修改 HiAgent 或火山知识库调用方式，不进行 Vercel 部署，也不删除现有用户、知识库、文档、会话或证据数据。
