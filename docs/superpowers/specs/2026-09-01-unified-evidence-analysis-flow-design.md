# 语证统一证据分析入口设计

## 目标

知识库详情页只承担资料管理：上传文件、保存文字、检查文字、修改尚未使用的文字以及移入回收站。删除文字资料下方的四张独立分析卡和“开始分析／重新分析”按钮。所有分析统一从“开始证据问答”进入。

## 用户流程

1. 用户上传文件，或粘贴并保存一份文字资料。
2. 已保存文字立即出现在证据问答页左侧资料架，无需提前分析。
3. 用户选择一份或多份资料，在底部输入自己的分析需求。
4. 系统生成持久化问题卡片；完成后在卡片详情中展示回答和证据。
5. 文字资料第一次进入证据问答时自动锁定，之后不可修改；如需更改，先移入回收站，再新建一份文字资料。

## 页面变化

### 知识库详情

- 保留文件上传区。
- 保留文字资料的新建、保存、选择、修改和移入回收站。
- 移除四张结论卡。
- 移除单独的文字分析按钮与分析状态文案。
- 资料区末尾提供明确操作按钮，引导进入“开始证据问答”。

### 证据问答

- 左侧资料架同时显示：处理完成的上传文件、所有已保存且未删除的文字资料。
- 未选择资料时，分析当前知识库中全部可用资料。
- 选中文字并提交问题后，服务端在发送 HiAgent 请求前写入锁定时间。
- 分析结果仍以问题卡片、全屏详情和证据列表展示，不再复制回知识库详情页。

## 数据规则

- 新建文字资料保存成功后，文档状态直接标记为可用于问答。
- 旧的已保存文字资料即使状态仍为 `STORED`，也应被问答页识别为可用文字来源。
- 上传文件仍须保持 `READY` 才能用于问答，避免把尚未经过学校文档处理的文件当成已检索资料。
- `analysis_started_at` 继续作为文字不可编辑的锁定依据，但锁定动作从独立分析接口迁移到证据问答提交。
- 保留现有分析字段和旧接口以兼容历史数据，不在本次变更中破坏或删除数据库结构。

## 错误与安全

- HiAgent 失败或超时时，问题卡片显示失败状态，原始资料保持锁定和完整。
- 不在浏览器代码中读取、返回或显示 HiAgent API 密钥。
- 不修改学校 HiAgent 应用、工作流或发布配置。
- 不删除现有资料；测试数据也不自动清理。

## 验收标准

- 知识库详情页不再出现四张独立分析卡和文字“开始分析”按钮。
- 新保存文字无需预分析即可在证据问答左侧选择。
- 第一次使用文字提问后，返回知识库详情时不再出现修改入口。
- 上传文件仍只有处理完成后才能进入资料架。
- 问题卡片、搜索、分页、全屏详情、回收站和恢复功能保持正常。
- 完整测试、Lint、TypeScript 和生产构建通过。
