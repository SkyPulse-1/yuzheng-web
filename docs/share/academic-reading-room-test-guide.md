# 语证“学术阅览室”本地测试指南

本指南用于在正式部署前检查本地成品。测试过程中不需要复制、展示或发送任何 API 密钥。

## 第一次使用前：执行一次数据库升级

1. 打开 Supabase 项目。
2. 进入 **SQL Editor**，点击 **New query**。
3. 打开本项目中的 `supabase/migrations/202609010001_create_academic_reading_room.sql`。
4. 复制文件里的全部 SQL，粘贴到 Supabase SQL Editor。
5. 点击 **Run**。成功后无需重复执行。

这一步只增加新字段、索引和回收站清理函数，不会删除现有知识库、文档或账号。

## 打开本地版

在项目目录运行：

```powershell
npm run dev -- -p 3100
```

浏览器打开 `http://localhost:3100`。如果终端显示端口已被占用，说明本地版可能已经在运行，可以直接打开网址。

## 建议测试顺序

1. 使用测试账号登录，确认工作台显示账号名和最近知识库。
2. 新建或打开一个知识库。
3. 在“文字资料”中填写标题与正文，点击“保存文字资料”。
4. 保存后先检查内容；点击“开始分析”后，确认标题和正文不再提供修改入口。
5. 等待四张结论卡出现：内容摘要、关键观点、原文依据、信息不足与歧义。
6. 将鼠标移到总结内容上，确认右侧显示来源原文上下文，并且远处文字逐渐变淡。
7. 打开“证据问答”，在左侧选择一份或多份资料，在底部输入自己的分析需求。
8. 确认右侧先出现“正在分析”卡片，完成后卡片保留；点击卡片可全屏查看回答与证据。
9. 测试问题搜索、加载更多和删除确认。
10. 删除一份文字资料或文件，打开“回收站”，确认能看到剩余天数并可以恢复。

## 当前学校接口的影响

- 粘贴文字可以直接保存并交给 HiAgent 分析。
- 上传文件会先安全保存；是否能进入文件检索问答，取决于学校是否开放文档上传/知识库处理接口。
- 如果混选了文字和尚未完成学校处理的文件，界面会明确提示，不会把没有证据的内容当成结论。

## 测试完成标准

- 页面没有白屏、错位或看不懂的技术提示。
- 所有主要按钮都能点击，并有处理中、成功或失败反馈。
- 每份结论都能看到来源；没有可靠来源时显示“暂未得到可靠结果”。
- 刷新页面或换设备登录后，已保存的文字资料和问题卡片仍然存在。
- 删除资料后 30 天内可恢复。
