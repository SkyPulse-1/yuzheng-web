# 语证测试版分享说明

这份说明用于把当前未部署版本交给其他人本地实验。分享时只发送源码包或 GitHub 链接，不发送任何 `.env.local` 文件、API Key、Secret Key、数据库导出或个人测试数据。

## 测试者本地启动

在 Windows PowerShell 中执行：

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

然后打开 `http://localhost:3000`。端口被占用时，以终端显示的地址为准。

测试者需要使用自己的 Supabase 项目配置。至少需要填写 Supabase 公共 URL、Publishable Key、服务端 Secret Key、用户名登录签名密钥和恢复码密钥。服务端变量只放在测试者自己的 `.env.local` 中。

## 推荐验收顺序

1. 注册一个不重复的用户名，并退出后重新登录。
2. 创建、编辑和打开知识库。
3. 上传 PDF、DOCX、TXT 小文件，确认列表显示“已保存”。
4. 验证超限提示：PDF 100MB、DOCX 50MB、TXT 30MB。
5. 查看并下载自己上传的文件，确认未登录或其他账号不能访问。
6. 打开证据问答页面，确认没有“可分析”文档时输入框被禁用并显示清楚说明。
7. 返回首页，确认示例证据卡、最近内容区域和导航正常。

## 当前已知范围

学校的独立文档处理上传服务地址和多用户隔离确认尚未提供。因而文件会安全保存，但不会伪装成已经进入知识库；真实证据问答需要学校服务接通后才能验收。

HiAgent 的服务端配置只能由项目拥有者或学校管理员提供给部署环境。测试者不需要、也不应该获得你的 HiAgent API Key。

## 正式部署

当前版本不包含 Vercel 部署。只有所有修改完成、学校接口和隔离规则确认后，才配置部署环境并发布正式网址。
